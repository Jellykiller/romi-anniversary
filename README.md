# رومی، معجزه‌ی نیمه‌شب — نسخه‌ی کامل اولیه

## فایل‌ها
- `index.html` — همه‌ی بخش‌های سایت
- `style.css` — طراحی واکنش‌گرا و موبایل‌محور
- `script.js` — ستاره‌ها، کنترل موسیقی، پاکت‌های نامه و پایان تعاملی
- `assets/` — محل عکس‌ها و فایل موسیقی

## شخصی‌سازی عکس‌ها
عکس‌های خودت را داخل `assets/` قرار بده و نام فایل‌ها را مطابق فهرست زیر بگذار:
- `PHOTO-01.jpg` — عکس بخش داستان آشنایی
- `PHOTO-02.jpg` — خاطره‌ی اول
- `PHOTO-03.jpg` — خاطره‌ی دوم
- `PHOTO-04.jpg` — خاطره‌ی سوم
- `PHOTO-05.jpg` — عکس رومی
- `PHOTO-06.jpg` — عکس دونفره‌ی آینده/خاطره

می‌توانی از JPG، PNG یا WebP استفاده کنی؛ اگر نام یا پسوند را عوض کردی، مسیر `src` همان تصویر را در `index.html` هم تغییر بده. پیشنهاد: برای موبایل تصاویر را فشرده و ترجیحاً زیر 500 کیلوبایت نگه دار.

## موسیقی
یک فایل پیانوی دارای مجوز استفاده با نام `piano.mp3` داخل `assets/` قرار بده. موسیقی فقط وقتی کاربر دکمه‌ی «پیانوی ما» را می‌زند پخش می‌شود؛ پخش خودکار ندارد.

## تغییر متن‌ها
در `index.html` عبارت‌های داخل کروشه مثل `[ویژگی اول رومی]` و متن‌های نمونه‌ی خاطرات را با جزئیات واقعی جایگزین کن. در `script.js` هم متن سه پاکت نامه داخل `letterData` قابل ویرایش است.

## اجرای محلی
`index.html` را در مرورگر باز کن. اگر مرورگر در پخش موسیقی یا مسیرها محدودیت ایجاد کرد، از افزونه‌ی Live Server در VS Code استفاده کن.

## انتشار در GitHub Pages
1. فایل‌ها و پوشه‌ی `assets` را در ریشه‌ی مخزن GitHub آپلود کن.
2. به **Settings → Pages** برو.
3. در بخش Build and deployment، گزینه‌ی Deploy from a branch را انتخاب کن.
4. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و ذخیره کن.
5. پس از انتشار، لینک GitHub Pages را باز کن.

## نکته‌های مهم
- سایت فریم‌ورک ندارد و برای موبایل طراحی شده.
- فونت‌ها از Google Fonts می‌آیند و برای بارگیری آن‌ها اینترنت لازم است؛ در غیر این صورت فونت جایگزین نمایش داده می‌شود.
- عکس‌های نمونه عمداً وجود ندارند؛ جای آن‌ها را با عکس‌های خودت پر کن.
- برای انتشار عمومی، فقط عکس‌هایی را قرار بده که هر دو نفر با نمایش آنلاین آن‌ها راحت هستید.
